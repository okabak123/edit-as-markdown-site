Install the beta

Install Edit as Markdown for Jira

Only a Jira site admin can install apps. If you aren’t an admin, send this page (or the button’s link) to your Jira admin.

  1. Open the install link above and sign in to Atlassian if asked.
  2. Choose the Jira Cloud site to install it on.
  3. Review and approve the three permissions (scopes): read issues and comments, write issues and comments, and read the current user. Then confirm the install.
  4. Open any Jira issue, click the ••• (more actions) menu at the top right of the issue, and choose Edit as Markdown for Jira.

To remove it: in Jira go to Settings (⚙) → Apps → Manage apps, expand Edit as Markdown for Jira and click Uninstall. The app stores no data, so nothing is left behind. Content you saved stays in Jira as normal.

What it does

The app opens an issue’s description, or any comment you’re allowed to edit, in a full-screen Markdown editor with a live Preview and a Diff of exactly what will change. When it opens, it checks that converting the content to Markdown and back reproduces the stored Jira document. Anything Markdown can’t express is kept as a protected item and saved back exactly as it was.

How to open it

  1. Open an issue in Jira Cloud (new issue view).
  2. Click ••• (more actions) at the top right of the issue and choose Edit as Markdown for Jira.
  3. Pick Description or a comment in the Edit menu. Comments are listed by author, date and time, with a short snippet.
  4. Edit the text, check Preview or Diff, then click Save (or press Ctrl/⌘+S). The issue view refreshes.

Panels and task lists are editable as plain text:

> [!INFO]
> Release notes are due on **Friday**.

- [x] Write the changelog
- [ ] Tag the release

Panel types: [!INFO], [!NOTE], [!WARNING], [!ERROR], [!SUCCESS].

Locked tokens and blocks

Jira content with no Markdown equivalent is shown as a protected item. You can move or delete it, but its inside isn’t editable in Markdown:

You seeWhat it is
⟦@Jane#i1⟧An inline item: mention, emoji (including custom), status, date, smart link, or text with colour/underline.
```adf-b2 … ```A locked block: expand, media, macro, custom panel, merged-cell table and similar. The block shows a readable summary.

If a save would remove a protected item, the app names it and asks first. Edit those items in Jira’s own editor.

Good to know

  • Permissions: if you can’t edit the issue or comment, the editor opens read-only and tells you why. Comment restrictions (for example “Administrators”) are kept.
  • Conflicts: if someone else changed the content while you were editing, the app doesn’t overwrite it. Use Copy my Markdown, then Reload latest.
  • Status line: “Lossless round trip verified” means an unchanged save stores the same document. “Lossless (only trailing spaces trimmed)” means invisible spaces at the ends of some lines are dropped.

Limitations (beta)

  • Jira Cloud only, in the new issue view. Confluence isn’t supported yet.
  • Jira rejects rich text above roughly 200 KB per field. The app warns you as you get close to that.
  • The Esc key and Jira’s own close button close the editor without asking about unsaved changes. The app’s Cancel button does ask.
  • Markdown can’t keep spaces at the very start or end of a line or table cell.
  • Rare content may not round-trip exactly. The app then shows a red warning listing the differences, and won’t save until you tick “Save anyway”.

Install and remove

  • Install: a Jira site admin opens the installation link we share and picks the site. The app asks for three permissions: read issues and comments, write issues and comments, and read the current user.
  • Update: new versions arrive automatically. If a version ever needs new permissions, a site admin is asked to approve them first.
  • Remove: Jira → Settings → Apps → Manage apps → Edit as Markdown for Jira → Uninstall. The app stores nothing, so nothing is left behind. Content you saved stays in Jira as normal.

Privacy and security

The app runs entirely on Atlassian’s platform. It stores no personal data, sends no data outside Atlassian and runs no analytics. See the privacy policy and the security statement. Report vulnerabilities to security@grotesque.ltd.
